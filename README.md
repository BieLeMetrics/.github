# .github

Organisationsweite GitHub-Konfiguration von **BieLeMetrics**.

- [`profile/README.md`](profile/README.md) – wird von GitHub als
  Startseite der Organisation unter
  <https://github.com/BieLeMetrics> angezeigt.

Dieses Repository ist **öffentlich**, weil GitHub das Profil-README einer
Organisation nur aus einem öffentlichen `.github`-Repository ausliest. Es
enthält deshalb ausschließlich Inhalte, die für die Öffentlichkeit bestimmt
sind – kein Code, keine Betriebsdaten, keine Kundendaten.

Die Website selbst liegt in `BieLeMetrics-Website`, die produktiven Systeme in
den privaten Repositories der Organisation.
